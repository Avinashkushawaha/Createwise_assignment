# 📰 AI Article Manager Dashboard

A modern dashboard interface for managing AI-generated articles, built using **React.js**, **ShadCN UI**, and **Tailwind CSS**. This project showcases UI functionality like tabs, tables, and filters with an elegant, responsive layout.
